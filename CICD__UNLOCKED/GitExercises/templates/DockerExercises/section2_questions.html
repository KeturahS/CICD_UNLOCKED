D
מהו Docker?

Docker הוא פלטפורמת קוד פתוח שמאפשרת לפתח, להפיץ ולהריץ אפליקציות בסביבות מבודדות הנקראות קונטיינרים (containers). הטכנולוגיה מאפשרת לארוז אפליקציה יחד עם כל הדרישות והתלויות שלה לתוך יחידה סטנדרטית אחת.

Docker פותח לראשונה ב-2013 על ידי חברת dotCloud (שלימים שינתה את שמה ל-Docker, Inc) והפך במהירות לסטנדרט תעשייתי לפיתוח ופריסת אפליקציות.

למה משתמשים ב-Docker?

  • עקביות סביבה: "עובד במחשב שלי" כבר לא תירוץ - Docker מבטיח שהאפליקציה תרוץ באותה צורה בכל סביבה
  • בידוד: אפליקציות רצות בסביבות מבודדות ללא הפרעה הדדית
  • יעילות משאבים: קל יותר וקטן יותר ממכונות וירטואליות מסורתיות
  • מהירות פריסה: קונטיינרים מופעלים במהירות ומאפשרים סקילביליות גבוהה
  • גמישות: תומך במגוון רחב של אפליקציות ושפות תכנות
  • אקוסיסטם עשיר: מאגר ענק של תמונות (images) מוכנות לשימוש

בניית Image

בשלב זה יוצרים תמונת Docker (Docker Image) באמצעות Dockerfile. התמונה מכילה את האפליקציה וכל התלויות שלה.

דוגמה לפקודה:

docker build -t my-app:1.0 .

דחיפה למאגר (Push to Registry)

לאחר בניית התמונה, ניתן לדחוף אותה למאגר תמונות כמו Docker Hub, כדי שאחרים יוכלו להשתמש בה.

דוגמה לפקודה:

docker push username/my-app:1.0

משיכה מהמאגר (Pull from Registry)

בשרת היעד, מושכים את התמונה מהמאגר כדי להשתמש בה.

דוגמה לפקודה:

docker pull username/my-app:1.0

הרצת קונטיינר (Run Container)

לבסוף, מריצים קונטיינר מהתמונה שנמשכה. הקונטיינר מכיל את האפליקציה הרצה בסביבה מבודדת.

דוגמה לפקודה:

docker run -d -p 8080:80 username/my-app:1.0

מושגים מרכזיים ב-Docker

C
Container (קונטיינר)

קונטיינר הוא מופע ריצה של תמונת Docker. זוהי סביבה מבודדת שמכילה את כל מה שהאפליקציה צריכה כדי לרוץ.

מאפיינים:

  • קל משקל ומכיל רק את הנדרש להרצת האפליקציה
  • מבודד מקונטיינרים אחרים ומהמערכת המארחת
  • ניתן להפעיל, לעצור, להשהות ולהסיר בקלות
  • השינויים בקונטיינר אינם משפיעים על התמונה המקורית
Docker Host
Container 1

I
Image (תמונה)

תמונת Docker היא תבנית לקריאה בלבד שממנה נוצרים קונטיינרים. התמונה מכילה את קוד האפליקציה, הספריות, התלויות, כלים וקבצים אחרים הנדרשים להרצת האפליקציה.

מאפיינים:

  • בנויה משכבות (layers) שמאפשרות שיתוף וחיסכון במקום
  • ניתנת לשיתוף במאגרי תמונות כמו Docker Hub
  • מוגדרת באמצעות Dockerfile
  • בעלת תגית (tag) שמציינת את הגרסה

D
Dockerfile

Dockerfile הוא קובץ טקסט שמכיל את כל הפקודות הנדרשות לבניית תמונת Docker. הוא מגדיר את הסביבה, התלויות והפעולות שיש לבצע כדי ליצור את התמונה.

דוגמה בסיסית:

FROM node:14 WORKDIR /app COPY package*.json ./ RUN npm install COPY . . EXPOSE 3000 CMD ["npm", "start"]

R
Registry (מאגר)

מאגר Docker הוא מקום לאחסון ושיתוף של תמונות Docker. המאגר הציבורי הנפוץ ביותר הוא Docker Hub, אך ניתן גם להקים מאגרים פרטיים.

סוגי מאגרים:

  • Docker Hub: מאגר ציבורי עם אלפי תמונות מוכנות לשימוש
  • מאגרים פרטיים: כמו Amazon ECR, Google Container Registry, Azure Container Registry
  • מאגרים מקומיים: כמו Docker Registry, Harbor

V
Volume (נפח)

נפחי Docker הם מנגנון לשמירת נתונים מחוץ לקונטיינר. הם מאפשרים לשמור מידע גם לאחר שהקונטיינר נמחק ולשתף מידע בין קונטיינרים.

סוגי נפחים:

  • נפחים מנוהלים (Managed volumes): נוצרים ומנוהלים על ידי Docker
  • נפחים מקושרים (Bind mounts): מקשרים תיקייה במערכת המארחת לתיקייה בקונטיינר
  • נפחי tmpfs: נשמרים רק בזיכרון ולא בדיסק

N
Network (רשת)

רשתות Docker מאפשרות לקונטיינרים לתקשר זה עם זה ועם העולם החיצוני. Docker מספק מספר סוגי רשתות מובנים.

סוגי רשתות:

  • bridge: הרשת המובנית המשמשת כברירת מחדל
  • host: משתמשת ברשת של המארח ללא בידוד
  • none: ללא גישה לרשת
  • overlay: מאפשרת תקשורת בין קונטיינרים במספר מארחי Docker
  • macvlan: מאפשרת להקצות כתובת MAC לקונטיינר

S
Swarm

Docker Swarm הוא כלי לניהול אשכול (cluster) של מארחי Docker. הוא מאפשר להפעיל ולנהל קונטיינרים על פני מספר מכונות.

מאפיינים:

  • מובנה בתוך Docker Engine
  • מאפשר סקילביליות אופקית
  • מספק איזון עומסים מובנה
  • תומך בעדכוני גרסה מתגלגלים (rolling updates)
  • מספק ניהול סודות (secrets) מובנה

פקודות Docker נפוצות

פקודות בסיסיות

# בדיקת גרסת Docker docker --version # הצגת מידע על התקנת Docker docker info # הצגת עזרה docker help

עבודה עם תמונות (Images)

# הצגת כל התמונות המקומיות docker images # חיפוש תמונה במאגר docker search ubuntu # משיכת תמונה מהמאגר docker pull ubuntu:20.04 # בניית תמונה מ-Dockerfile docker build -t my-app:1.0 . # דחיפת תמונה למאגר docker push username/my-app:1.0 # מחיקת תמונה מקומית docker rmi ubuntu:20.04 # הצגת היסטוריית שכבות של תמונה docker history ubuntu:20.04

עבודה עם קונטיינרים

# הרצת קונטיינר docker run -d -p 8080:80 nginx # הרצת קונטיינר עם שם docker run --name my-nginx -d nginx # הרצת קונטיינר עם נפח docker run -v /host/path:/container/path -d nginx # הרצת קונטיינר עם משתני סביבה docker run -e VAR_NAME=value -d nginx # הצגת קונטיינרים פעילים docker ps # הצגת כל הקונטיינרים (כולל כבויים) docker ps -a # עצירת קונטיינר docker stop container_id # הפעלת קונטיינר שנעצר docker start container_id # הפעלה מחדש של קונטיינר docker restart container_id # מחיקת קונטיינר docker rm container_id # מחיקת כל הקונטיינרים שאינם פעילים docker container prune

ניטור ודיבאג

# הצגת לוגים של קונטיינר docker logs container_id # מעקב אחר לוגים בזמן אמת docker logs -f container_id # הצגת סטטיסטיקות שימוש משאבים docker stats # הרצת פקודה בתוך קונטיינר פעיל docker exec -it container_id bash # הצגת תהליכים הרצים בקונטיינר docker top container_id # הצגת מידע מפורט על קונטיינר docker inspect container_id

עבודה עם נפחים (Volumes)

# יצירת נפח docker volume create my-volume # הצגת כל הנפחים docker volume ls # הצגת מידע מפורט על נפח docker volume inspect my-volume # מחיקת נפח docker volume rm my-volume # מחיקת כל הנפחים שאינם בשימוש docker volume prune

עבודה עם רשתות

# יצירת רשת docker network create my-network # הצגת כל הרשתות docker network ls # חיבור קונטיינר לרשת docker network connect my-network container_id # ניתוק קונטיינר מרשת docker network disconnect my-network container_id # הצגת מידע מפורט על רשת docker network inspect my-network # מחיקת רשת docker network rm my-network

ניקוי מערכת

# מחיקת כל הקונטיינרים, הרשתות והתמונות שאינם בשימוש docker system prune # מחיקת כל הקונטיינרים, הרשתות, התמונות והנפחים שאינם בשימוש docker system prune -a --volumes # הצגת מידע על שימוש בדיסק docker system df
