1. מה זה Git ו-GitHub ולמה זה חשוב?

Git היא מערכת לניהול גרסאות שמאפשרת למפתחים לעקוב אחרי שינויים בקוד, לעבוד בצורה שיתופית, ולחזור אחורה לגרסאות קודמות במקרה של טעות. GitHub היא פלטפורמה מקוונת שמבוססת על Git ומאפשרת שיתוף פעולה בין מפתחים מכל העולם.
