2. פקודות בסיסיות ב-Git

כאן תכיר את הפקודות הבסיסיות ביותר בשימוש יומיומי ב-Git כמו init, add, commit ו-status.

מה עושה הפקודה git init?

יוצרת עותק מרוחק של הפרויקט
יוצרת מאגר Git חדש בתיקייה
בודקת סטטוס הקבצים

מתי משתמשים בפקודה git add?

לאחר יצירת מאגר
כדי לשמור שינויים על הקוד
כדי להכין קבצים לקומיט
