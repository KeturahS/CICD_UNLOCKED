4. פקודות מתקדמות ב-Git

כאן תלמד על פקודות מתקדמות כמו git diff ו־.gitignore – כלים חשובים להתנהלות חכמה מול קוד במאגרים.

מה עושה הפקודה git diff?

מאחדת בין סניפים
מציגה הבדל בין שינויים שטרם נשמרו
שומרת שינויים עם תגית

מה המטרה של קובץ .gitignore?

למחוק את כל הקבצים
לשמור שינויים אוטומטית
להחריג קבצים מסוימים ממעקב Git
